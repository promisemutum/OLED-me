# Oledify

> A simple browser extension designed to simulate OLED-like contrast on standard screens through real-time canvas image processing and dynamic display profiles.

---

### Deployment & Testing
This repository is deployed on GitHub Pages for testing, staging, and previewing canvas processing and black-level rendering directly in the browser.

### Development Status
* **In Progress:** Optimizing deep-black pixel casting and dynamic contrast adjustment algorithms for non-OLED panels.
* **Current Version:** `v1.1.0`
